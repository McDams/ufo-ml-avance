# TP Machine Learning Avancé — Relevés Klaxo-3

Analyse reproductible de signalements d'OVNI : chargement robuste, typage, création d'une cible de canular, modélisation et vérification des fuites de données.

## Installation

```bash
pip install -r requirements.txt
python analyse.py
```

Le script télécharge lui-même les données dans `data/` et génère les résultats dans `outputs/`.
